# Объектное хранилище (Object Storage)

> Подсистема интеграции конфигураций **1С:Предприятие 8** с S3‑совместимыми объектными
> хранилищами: вынос присоединённых файлов из базы в хранилище, отложенная (асинхронная)
> обработка через очередь заданий, регламентное сопровождение и мониторинг.

## Возможности

- **Вынос файлов в S3.** Присоединённые файлы (подсистема БСП «Работа с файлами») автоматически
  выгружаются в объектное хранилище, а в базе остаётся ссылка на объект в хранилище.
- **S3‑коннектор** (`ох_КоннекторS3`) — загрузка, получение, удаление файлов, генерация
  подписанных ссылок (presigned URL), перечисление бакетов и объектов, определение MIME‑типа.
- **Асинхронная обработка** через очередь заданий и регламентное задание: операции над
  хранилищем не блокируют пользовательские транзакции.
- **Повторная обработка ошибок** с ограничением числа попыток и настраиваемой базовой задержкой
  (backoff) — устойчивость к временной недоступности хранилища.
- **Многопоточность.** Обработка очереди в несколько потоков с настраиваемым числом заданий на поток.
- **Регламентное сопровождение:** очистка выполненных заданий и удаление файлов по сроку хранения.
- **Мониторинг** выполнения заданий отдельным отчётом.
- **Мягкая (подписочная) интеграция:** регистрация файлов работает через подписки на события и
  корректно деградирует, если зависимости (БСП, «Работа с файлами», определяемые типы) не настроены.

## Как это работает

```
Запись/удаление присоединённого файла
        │
        ▼
Подписки на события  ─────►  Регистрация в очереди заданий
(ох_РегистрацияФайлов…)      (РегистрИнформации ох_ОчередьЗаданийОбъектногоХранилища)
                                     │
                                     ▼
                      Регламентное задание «Обработка заданий»
                      (ох_ОбработкаЗаданийОбъектногоХранилища)
                                     │
                          ┌──────────┴──────────┐
                          ▼                      ▼
                  ох_КоннекторS3          Повтор при ошибке
                  (загрузка/удаление/     (backoff, лимит попыток)
                   ссылка)                        │
                          │                       ▼
                          ▼             Мониторинг (отчёт)
                 S3‑совместимое
                 объектное хранилище
```

Отдельное регламентное задание «Регламентные операции» выполняет обслуживание: чистит историю
заданий и удаляет файлы по сроку хранения.

## Требования

Протестировано на следующих версиях:

| Компонент                     | Версия            |
|-------------------------------|-------------------|
| Платформа 1С:Предприятие      | 8.5.1+ (режим совместимости 8.5.1) |
| БСП (Библиотека стандартных подсистем) | 3.1.11.466 |
| Коннектор HTTP                | 2.6.1             |
| 1С:EDT                        | для работы с исходниками проекта |

Конфигурация, в которую внедряется подсистема, должна включать подсистему БСП
**«Работа с файлами»** и настроенные определяемые типы владельцев/файлов — иначе интеграция
переходит в «спящий» режим и файлы не регистрируются.

## Установка

Подсистема поставляется как файл конфигурации/исходники EDT и внедряется в целевую конфигурацию
через сравнение и объединение.

### Через Конфигуратор

1. **Конфигурация → Сравнить, объединить с конфигурацией из файла…** и укажите файл подсистемы.
2. Снимите галочку с **корня** конфигурации.
3. **Действия → Отметить по подсистемам файла**.
4. Выберите подсистему **`ох_ОбъектноеХранилище`**.
5. Нажмите **Выполнить → Продолжить**.
6. Когда конфигуратор попросит **указать источники подписок**, укажите их для:
   - `ох_РегистрацияФайловОбъектногоХранилищаПриЗаписи`
   - `ох_РегистрацияФайловОбъектногоХранилищаПередУдалением`
   - `ох_РегистрацияФайловОбъектногоХранилищаПриЗаписиНабораЗаписей`

   Источники должны соответствовать типам присоединённых файлов вашей конфигурации
   (определяемый тип `ох_ПрисоединенныеФайлыОбъектногоХранилища`).

7. Обновите конфигурацию базы данных (F7).

### Через 1С:EDT

```sh
git clone https://gitlab.com/Vladimirov-Maxim/object-storage.git
```

Импортируйте проект `ObjectStorage` в рабочую область 1С:EDT
(**File → Import → 1C:EDT → Existing Projects into Workspace**) и подключите к целевой информационной базе.

## Настройка

После внедрения задайте параметры в константах и справочниках подсистемы:

1. **Справочник «Сервисные аккаунты» (`ох_СервисныеАккаунтыОбъектныхХранилищ`)** — адрес сервера,
   регион, тип аутентификации, идентификатор и секретный ключ доступа к хранилищу. Проверить
   соединение можно методом `ох_КоннекторS3.ПроверитьПодключение`.
2. **Справочник «Бакеты» (`ох_БакетыОбъектныхХранилищ`)** — имена бакетов в хранилище.
3. **Константы** — параметры по умолчанию и режим работы очереди:

   | Константа | Назначение |
   |-----------|-----------|
   | `ох_ИспользоватьИнтеграцию` | Главный переключатель интеграции |
   | `ох_СервисныйАккаунтПоУмолчанию` | Аккаунт по умолчанию |
   | `ох_БакетПоУмолчанию` | Бакет по умолчанию |
   | `ох_МаксимальноеКоличествоПотоковОбработкиЗаданий` | Число потоков обработки очереди |
   | `ох_КоличествоЗаданийВыполняемыхОднимПотоком` | Заданий на поток за один проход |
   | `ох_ОбрабатыватьОшибкиПовторно` | Включить повторную обработку ошибок |
   | `ох_МаксимальноеКоличествоПопытокОбработки` | Лимит попыток |
   | `ох_БазоваяЗадержкаПриПовторнойОбработки` | Базовая задержка (backoff) |
   | `ох_КоличествоДнейХраненияЗаданий` | Срок хранения истории заданий |
   | `ох_КоличествоДнейХраненияФайлов` | Срок хранения файлов |

4. Включите регламентные задания **«Обработка заданий объектного хранилища»** и
   **«Регламентные операции объектного хранилища»**.

Для интерактивной работы и диагностики предусмотрена обработка **«Работа с объектным хранилищем»**
(`ох_РаботаСОбъектнымХранилищем`).

## Использование

Основной программный интерфейс — общий модуль **`ох_ОбъектноеХранилище`**.

```bsl
// Загрузка файла в объектное хранилище
ПараметрыРаботы = ох_ОбъектноеХранилище.НовыйПараметрыРаботыСОбъектнымХранилищем();
// ...заполнить сервисный аккаунт и бакет...

ПараметрыЗагрузки = ох_ОбъектноеХранилище.НовыйПараметрыЗагрузкиФайла();
ПараметрыЗагрузки.ДанныеФайла.ДвоичныеДанныеФайла = ДвоичныеДанные;

Результат = ох_ОбъектноеХранилище.ЗагрузитьФайл(ПараметрыРаботы, ПараметрыЗагрузки);

// Получение подписанной ссылки на файл
ПараметрыСсылки = ох_ОбъектноеХранилище.НовыйПараметрыПолученияСсылки();
ДанныеСсылки = ох_ОбъектноеХранилище.ПолучитьСсылкуФайла(ПараметрыРаботы, ПараметрыСсылки);

// Удаление файла
ПараметрыУдаления = ох_ОбъектноеХранилище.НовыйПараметрыУдаленияФайла();
ох_ОбъектноеХранилище.УдалитьФайл(ПараметрыРаботы, ПараметрыУдаления);
```

Низкоуровневые операции над хранилищем доступны в модуле **`ох_КоннекторS3`**:
`ПроверитьПодключение`, `ЗагрузитьФайл`, `ПолучитьФайл`, `УдалитьФайл`, `ПолучитьСсылку`,
`ВсеБакетыХранилища`, `ПолучитьФайлыБакета`, `MIMEТипДляРасширенияФайла`.

## Состав подсистемы

| Тип объекта | Объект | Назначение |
|-------------|--------|-----------|
| Справочник | `ох_СервисныеАккаунтыОбъектныхХранилищ` | Учётные данные доступа к хранилищу |
| Справочник | `ох_БакетыОбъектныхХранилищ` | Бакеты хранилища |
| Справочник | `ох_НастройкиРегистрацииФайловОбъектногоХранилища` | Правила регистрации файлов |
| Общий модуль | `ох_ОбъектноеХранилище` | Основной программный интерфейс |
| Общий модуль | `ох_КоннекторS3` | Клиент S3‑совместимого API |
| Общий модуль | `ох_РегистрацияФайловОбъектногоХранилища` | Регистрация файлов в очереди |
| Общий модуль | `ох_ОбъектноеХранилищеСлужебный` / `…ПовтИсп` | Служебные и повторно используемые методы |
| Общий модуль | `ох_ОбщегоНазначения(Клиент/КлиентСервер)` | Вспомогательные методы |
| Регистр сведений | `ох_ОчередьЗаданийОбъектногоХранилища` | Очередь операций |
| Регистр сведений | `ох_ЗаданияДляОбработкиОбъектовХранилища` | Задания на обработку |
| Регистр сведений | `ох_ПрисоединенныеФайлыВХранилище` | Соответствие файлов и объектов в хранилище |
| Регламентное задание | `ох_ОбработкаЗаданийОбъектногоХранилища` | Обработка очереди |
| Регламентное задание | `ох_РегламентныеОперацииОбъектногоХранилища` | Очистка и удаление по сроку |
| Отчёт | `ох_МониторингВыполненияЗаданийОбъектногоХранилища` | Мониторинг очереди |
| Обработка | `ох_РаботаСОбъектнымХранилищем` | Интерактивная работа и диагностика |
| Определяемые типы | `ох_ВладелецПрисоединенныхФайлов…`, `ох_ПрисоединенныеФайлы…` | Точки расширения под конфигурацию |

## Соглашения о префиксах

Все объекты подсистемы имеют префикс **`ох_`** (от «объектное хранилище»), что исключает
конфликты имён при внедрении в произвольную конфигурацию.

## Разработка

Проект ведётся в **1С:EDT**; исходники хранятся в текстовом формате в каталоге
[`ObjectStorage/src`](ObjectStorage/src). Рекомендуется соблюдать
[стандарты разработки 1С](https://its.1c.ru/db/v8std) и стиль оформления БСП.

## Совместимость

Режим совместимости конфигурации — **8.5.1**. Хранилище должно поддерживать S3‑совместимый
протокол (проверялось на типовых S3‑совместимых сервисах). Для сетевого взаимодействия
используется библиотека **Коннектор HTTP 2.6.1**.
